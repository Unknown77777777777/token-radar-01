Every row is scored by the same function, from the snapshot's own figures only. No protocol name is ever special-cased.

What counts as a launch

A protocol is on the board when it records no token — market cap, CoinGecko id and symbol are all absent from its record — and it is launchable. Excluded, even when they record no token:

  • Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC and CEX categories.
  • Names carrying a whole word wrapped, staked or staking.
  • Names beginning with an exchange name (Binance, Coinbase, Bybit, Kraken, Bitget, OKX, Bitfinex, Gemini).
  • Names ending in a version marker such as V2, v2 or 2.0.

Wrapped, staked, bridged and exchange products are not launches waiting to happen: they are versions of tokens that already trade. The board ranks the whole launchable set — 198 rows on this snapshot — never a top-N cut.

A note on wording

This radar says a protocol “records no token”, never that it “has no token”: the snapshot is a record, and absence from the record is all the radar can claim.
